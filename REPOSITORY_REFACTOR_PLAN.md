# Repository refactor record

The repository reorganization is complete. This file records the resulting
boundaries; use the [repository guide](docs/REPOSITORY_GUIDE.md) for practical
navigation and the [canonical pipeline guide](docs/UNIRST2_PIPELINE.md) for
workflow details. It replaces the earlier forward-looking migration checklist,
whose proposed paths and acceptance criteria are no longer the source of
truth.

## Active project boundary

The supported experiment compares PCC, full eRST, full RST-DT, and NLDT on a
matched HC3 cohort with shared EDU segmentation. The reported workflow is
in-HC3 only; OOD and Human Detectors work remains archival side-study material.
The workflow is configured by [`configs/canonical.json`](configs/canonical.json)
and orchestrated by [`run_canonical.py`](run_canonical.py).

```text
scripts/prepare/       aligned records, graphs, and M3 catalogs/distributions
scripts/canonical/     matrices, matched cohort, models, inference, synthesis
scripts/review/        optional qualitative review utilities
tos/                   shared parser, dataset, and analysis code
docs/                  workflow, mapping, and tracked result snapshots
archive/code/          versioned legacy, superseded, and side-study code
archive/docs/          historical plans and flow audits
```

## Reproducibility boundary

The canonical data expected under `data/unirst2` and `data/motifs2`, as well as
the complete generated outputs under `artifacts/canonical` and
`artifacts/work`, are local-only and ignored by Git. The tracked research
report, paper tables, selected figures, and pooled relation-frequency table
are available under the repository root and `docs/`. A fresh clone therefore
supports inspection of the reported summary, but needs the external input
bundle and a regenerated run to reproduce or verify the complete analysis.

Run the active checks from the repository root:

```bash
python -m pytest -q
python run_canonical.py verify --config configs/canonical.json
```

The verification command requires the local canonical artifacts. See the
[repository guide](docs/REPOSITORY_GUIDE.md) for input restoration notes and
the [pipeline guide](docs/UNIRST2_PIPELINE.md) for stage dependencies and
verification details.

## Archive policy

Archived source code is preserved in Git under `archive/code/`; it is not
imported by or required for the active pipeline. Generated exploratory and
superseded artifacts are excluded from Git and may exist only in a research
working copy or external storage. `archive/manifest.json` is a local-only
inventory generated by `python -m scripts.archive_manifest`; it is not a
checked-in data restoration manifest. See [`archive/README.md`](archive/README.md)
for details.
